EARNOS
======

EARNOS is a digital earning platform.

Project structure
-----------------

index.html
    Main application page.

css/
    Main interface styles.

css/styles.css
    Dark Pro visual design.

css/responsive.css
    Mobile and responsive adjustments.

js/
    Application JavaScript files.

js/config.js
    Supabase configuration.

js/app.js
    Main application logic.

js/database.js
    Database communication layer.


IMPORTANT SECURITY NOTE
-----------------------

Only the Supabase Publishable key is used
in the browser application.

Never put a Supabase Secret key or
Service Role key inside:

- index.html
- config.js
- app.js
- database.js
- any other public JavaScript file
